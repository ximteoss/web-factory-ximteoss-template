# SKILL: EDITORIAL UI & IMPECCABLE TASTE

1. **Generous Negative Space:** Enforce breathing room using large vertical section padding (`py-24 md:py-32`) and constrained containers (`max-w-7xl mx-auto px-6`). Never crowd UI elements.
2. **Extreme Typographic Hierarchy:** Pair oversized, tight-tracked display headings (`text-5xl md:text-7xl font-light tracking-tight leading-[1.05]`) with micro-tracked uppercase eyebrow labels (`text-xs uppercase tracking-[0.25em]`).
3. **Hairline Borders Over Heavy Shadows:** Define cards and navigation bars with subtle 1px translucent borders (`border-white/10` or `border-black/10`) and glassmorphism (`backdrop-blur-md`) rather than dated drop shadows.
4. **Tinted Neutrals:** Ground designs in warm or cool tinted neutrals (e.g., `#0D0C0B` warm obsidian, `#F8F6F1` alabaster paper) paired with a single purposeful accent color.
